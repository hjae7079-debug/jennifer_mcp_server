# AIOps 통합분석 패키지 v0.3.1 변경사항

## 반영
- ITSM 기본 수집 주기: 30초에서 300초(5분)로 변경
- Qwen2.5-Coder-14B 개발 지원 모델 오프라인 준비 기본 활성화
- 오프라인 사전검증 스크립트 추가
- 오프라인 번들에 Ollama 모델 데이터 압축본 포함
- API 이미지 태그 v0.3.1로 변경

## 아직 구현/검증되지 않은 항목
- Dify 서버 전체 오프라인 배포 및 플러그인 종속성
- 실제 ITSM MCP 서버 호출 및 기관별 JSON 스키마 매핑
- Jennifer 실제 MCP tool 호출(도구 스키마/응답 확보 후 구현)
- SIEM MCP 연동 및 조회 조건 구현
- 사용자 인증/RBAC/SSO와 HTTPS 운영 설정
- 실제 RTX 5080 GPU에서의 모델 추론 성능 및 폐쇄망 end-to-end 테스트

이 패키지는 설치 준비용 개선본이며, 실제 폐쇄망 설치 완료를 의미하지 않습니다.
