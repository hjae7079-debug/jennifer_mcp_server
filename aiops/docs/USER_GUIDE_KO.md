# AIOps 통합분석 대시보드 사용자 매뉴얼

## 1. 접속
- 대시보드: `http://10.148.216.55:18080`
- 별도 LLM 채팅 UI(Open WebUI): `http://10.148.216.55:18081`

두 화면은 서로 다른 UI입니다. 대시보드는 장애/이벤트와 분석 상태를 확인하고, Open WebUI는 로컬 LLM에 일반 질문을 입력하는 용도입니다.

## 2. 대시보드 첫 화면
상단에는 기관 수, 업무 수, 장애 건 수, 이벤트 건 수가 표시됩니다. 기관/업무 기준 API가 연결되지 않은 상태에서는 30/140을 임시 숫자로 표시하고, 임시값임을 함께 표시합니다. 장애/이벤트 건 수는 실제 이력 API에서 수집되어 DB에 저장된 레코드 수입니다.

장애분석과 이벤트분석은 각 최근 3건을 표시합니다. 카드에는 원본 ID, 기관명, 제목, 발생 시각, 분석 상태, 3줄 이내 요약이 표시됩니다. 카드를 클릭하면 상세 분석 화면으로 이동합니다.

탐지내역과 관찰대상은 각 최근 5건을 표로 보여줍니다. 표 내부 스크롤로 더 긴 내용을 확인합니다. 탐지/관찰 항목은 원본 종류와 원본 ID를 유지해 장애·이벤트 상세 화면으로 연결합니다.

## 3. 상태 표시 의미
- **이력 API 미설정**: URL/인증 설정이 없어 아직 조회할 수 없습니다.
- **조회 대기 / 상태 확인 필요**: API URL은 설정되어 있지만 Worker가 아직 성공/실패 결과를 기록하지 않았습니다.
- **조회 실패**: HTTP 요청 실패, 인증 실패 또는 응답 스키마 불일치 가능성이 있습니다. 운영 담당자에게 확인을 요청하세요.
- **발생 이력 없음**: API 조회가 성공했고 현재 반환 목록이 비어 있습니다.
- **분석 중**: 이력은 수집되었고 로컬 LLM 분석을 진행 중입니다.
- **분석 완료**: 분석 요약과 상세 내용이 저장되었습니다.
- **분석 실패**: 모델/API/Workflow 오류로 분석이 완료되지 않았습니다.

이력 API가 미설정이거나 조회 실패인 경우 이를 '발생 이력 없음'으로 오인하지 않도록 별도 상태로 표시합니다.

## 4. 상세 화면
상세 화면에는 개요, 타임라인, WEB, WAS, DB, AI 분석, 조치 이력, 보고서 탭이 있습니다. 현재 원본 JSON과 AI 분석은 실제로 저장된 값만 표시합니다. WEB/WAS/DB/조치 이력/보고서 데이터 소스가 연결되지 않은 탭은 '연동 대기'를 표시하며 임의의 데이터를 만들지 않습니다.

## 5. 테마와 검색
상단의 테마 버튼으로 밝은 테마/어두운 테마를 바꿀 수 있습니다. 선택은 해당 브라우저의 localStorage에 저장됩니다. 장애/이벤트/탐지/관찰 목록의 검색창은 현재 불러온 목록에서 ID, 기관, 업무, 제목/내용을 검색합니다.

## 6. 모의 데이터
기본 설정은 `DATA_MODE=live`입니다. 실제 API가 연결되지 않은 경우 운영 데이터처럼 보이는 예시를 만들지 않습니다. UI 개발 테스트가 필요할 때만 `.env`에서 `DATA_MODE=mock`으로 바꾸세요. 모의 ID는 `DEMO-`로 시작하고 화면에 모의 데이터 배너가 표시됩니다. 운영망에서는 모의 모드를 사용하지 마세요.
